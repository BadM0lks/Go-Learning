# Go-Learning

Repositorio de aprendizaje de Go basado en ejercicios prácticos y proyectos reales. Incluye código, objetivos, conceptos, dudas resueltas, pruebas y comparaciones con Dart y Python, documentando mi evolución hasta desarrollar **GoMail**, un sistema de envío de correos electrónicos.

## Probar el código

```bash
go test ./...
```

Cada ejercicio tiene su propia carpeta, código ejecutable, pruebas y documentación sobre el objetivo, las dudas y los límites de lo aprendido.
