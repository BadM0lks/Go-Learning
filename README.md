# Go-Learning

Repositorio de aprendizaje de Go basado en ejercicios prácticos y proyectos reales. Incluye código, objetivos, conceptos, dudas resueltas, pruebas y comparaciones con Dart y Python, documentando mi evolución hasta desarrollar **GoMail**, un sistema de envío de correos electrónicos.

## Progreso

| Ejercicio | Tema | Estado |
| --- | --- | --- |
| [01](ejercicios/01-validacion/) | Validación de cadenas y `strings.TrimSpace` | Completado |
| [02](ejercicios/02-structs/) | Estructuras `struct` y funciones de validación | Completado |
| [03](ejercicios/03-metodos-punteros/) | Métodos, punteros, estados y retornos anticipados | Completado |

## Probar el código

```bash
go test ./...
```

Cada ejercicio tiene su propia carpeta, código ejecutable y documentación sobre el objetivo, las dudas y los límites de lo aprendido. Los ejercicios 01 y 02 incluyen pruebas automatizadas; el 03 documenta las comprobaciones manuales realizadas.
